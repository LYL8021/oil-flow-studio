# 油路工坊

拖放油槽、閥門、彎頭、過濾器、三通、四通、用油端、直油管、盲封與流量計，建立油路並觀察通斷。

## 使用方式

1. 從左側拖入元件，或點擊元件新增。
2. 直接點擊元件的圓形接點開始接管，再點另一個元件的接點完成。滑到元件本體可直接選取、拖動，不用反覆切換 V／C；接管途中保持接管，可按 Esc 取消。手掌 H 或中鍵可平移畫布。
3. 點擊閥門下方的「開啟／關閉」，下游管線會依連通情況改變顏色。
4. 選取元件後，可在右側修改名稱、編號、位置與任意角度，按 R 旋轉 90°、Delete 刪除。直油管可修改長度，兩端可留空或連接盲封；盲封只允許一段接管。流量計可串接並隨油源顯色，不產生虛構流量。
5. 油槽可在右側切換供油，並選擇燃料油（橘色）或柴油（淺藍色）。三通用於三路分流，四通提供四個彼此連通的接點，可由任意一端供油；交叉的油管不會自動連接。
6. 專案會自動保存在瀏覽器。匯出 JSON 可備份、重新匯入繼續修改；SVG 可保存圖檔。

橘色表示與燃料油來源連通，淺藍色表示與柴油來源連通，灰色表示未連通。兩種來源同時連通時以橘藍雙色管線表示，不計算混油比例。

新增油管前可切換「直角／自由斜走」。自由斜走可在連接途中點畫布加入轉折；接好後可拖曳轉折點。

新增油管前可在工具列選擇一般管、跨管或地下管；點選既有油管可在右側改變型式。跨管在真正交叉的位置畫拱橋，地下管以虛線表示。兩種型式都保留原來的接點與通油判斷。關閥後，上游保留顏色；下游若有旁通或其他油槽供應，仍會有顏色。本程式模擬通斷，不計算壓力、流量或殘留油量。

## 本機啟動

使用 Python 3，在專案目錄執行：

```
python3 -m http.server 4173 --directory dist
```

再開啟 http://localhost:4173 。不需安裝套件。portable 目錄中的單檔 HTML 也可直接在瀏覽器開啟。

## 驗證

```
node tests/flow.test.mjs
```

測試涵蓋串聯關閥、分支、旁通與迴路、多油槽、停用油槽與無效接點。

## 圖片建立草稿

左側「從圖片建立草稿」可上傳 PNG、JPG 或 WebP。辨識在瀏覽器內進行，依設備編號推測種類與大致位置；未編號的符號可能遺漏，管線不會自動連接。建立後可用半透明底圖對照、修改元件種類與圖示外觀，並逐一標記確認。沒有辨識到編號時，可選「只載入底圖」描圖。

辨識引擎首度使用需載入約 7 MB 的同站資源；較大的圖片可能花較多時間。離線單檔版可保留底圖與既有草稿，但文字辨識請使用線上版。

閥門預設採兩側法蘭的對向三角形，過濾器預設採雙圓框；可於「圖示外觀」切換 M 電動閥、圓心閥與籃式過濾器。

油槽預設改為平面俯視圓形，圓內顯示槽號、容量（公秉）與油品。容量可於油槽屬性填寫；填寫容量不會影響本工具的通斷運算。

## 共用開發與部署

共用程式庫：https://github.com/LYL8021/oil-flow-studio 。各自的 GPT／Codex／Claude 程式助理需連接有寫入權的同一專案。從最新 `main` 建分支、檢查並透過 PR 合併；Git 自動部署接妥後，等發布成功再重新整理正式網址即可看到修改，並非逐字即時同步。本文件不代表部署已完成。

靜態發布目錄為 `dist`，免建置與依賴安裝，須保留完整 `vendor/ocr/`；測試用 `npm test`。執行 `python3 scripts/package-offline.py` 可產生 `portable/` 並更新離線下載 ZIP。

原 Sites 網址不會自動跟隨此 repo 更新；各自瀏覽器的油路圖也不互通，需匯出／匯入 JSON 分享。詳見 [AI_EDIT_GUIDE.md](AI_EDIT_GUIDE.md)、[AGENTS.md](AGENTS.md) 及 [CLAUDE.md](CLAUDE.md)。

## 圖面儲存區

按右上角「儲存圖面」，輸入名稱（例如「輸王田」）即可保存完整元件、管線、閥門狀態及參考底圖。下次開啟「圖面儲存區」，點名稱就能載入。已命名圖面修改後，按「更新這張圖面」保留最新內容；換一個名稱則另存新圖面。清單支援改名、匯出 JSON 與刪除，切換時會提醒尚未存入儲存區的修改，同名覆寫與刪除也會確認。

圖面保存在目前裝置、目前瀏覽器與同一網站網址中，不會同步給朋友或其他裝置。清除網站資料可能移除存檔，重要圖面請匯出 JSON 備份；舊網址的圖面可先匯出 JSON，再到新網址匯入並命名保存。原有草稿自動暫存與 JSON 匯入匯出仍可使用。

## 固定管線圖與作業項目

日常使用預設進入「作業模式」：左上選固定管線圖，左下列出該圖專屬的作業項目。點作業名稱即可套用全部閥門開關，圖面位置、油品與供油來源不變，顏色立即重新計算。也能手動調整閥門，再按「＋」或「儲存作業」命名保存；作業支援更新、改名與刪除。

新增或修改元件、接管時切到「編修圖面」，編好按「儲存管線圖」。圖面與作業分開保存，儲存作業不會覆寫固定圖的原始閥位或布局。接管、元件或閥門編號改變後，舊作業會標示不相容，需重新檢查並儲存。圖面 JSON 備份包含該圖所有作業；現有圖面會保留，作業仍儲存在目前瀏覽器。

## 底圖大小與立管閥

進入「編修管線圖與元件」，在畫布右上角按「調整底圖」，可設定底圖大小（25%～500%，保持比例）與 X／Y 位置。例如日南圖可先試 200% 或 300%。勾選「同步調整元件位置與管線轉折」可一起拉開既有元件的位置，元件本身尺寸不變；取消勾選只調整底圖。套用後會適合畫面，支援復原、重做與保存，使用滾輪仍可放大查看細節。

元件庫新增「立管閥」，採用地面往上管段的端視法蘭、閥桿符號；也可選取既有閥門，在「圖示外觀」切換。它與一般閥門相同，可旋轉、接管、開關及儲存作業配置。

所有元件的名稱和編號均可清空留白，儲存與 JSON 匯入匯出會保留空白；新增元件仍會提供可自行刪除的預設文字。

## 連續畫油管

編修時按「連續畫油管」或 C，在空白處點起點，沿途點擊加入管段與轉折，最後按右鍵或「完成繪製」。右鍵以最後一次點下的位置為終點，不會加入滑鼠預覽的尾段；Esc 取消整段草稿。預設直角折線，也能切換自由斜走。點既有元件接點可直接開始或完成接管；畫管時點既有管線可接出分支，新增的小圓點就是相通的接管點，可再接第三、第四條管線。單純交叉不會自動相通。

不需逐一擺直管、彎頭、三通或四通；這些舊元件仍在「其他管件」，既有圖面保持相容。立管閥改為一個中心接點，先後兩條管線分別接到閥的兩側，關閥仍會隔開兩側油路；中心已接滿兩端時需先移除原管線再修改。
